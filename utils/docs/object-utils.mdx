## API

### `isPlainObject(value)`

Returns `true` for a plain `{}` object — not `null`, not an array, not a class instance.

```ts
import { isPlainObject } from "@theholocron/object-utils";

isPlainObject({}); // true
isPlainObject([]); // false
isPlainObject(new Date()); // false
```

### `deepMerge(base, override)`

Deep-merge, `vite`-style: plain objects merge recursively, arrays concatenate (`base` first), `undefined` in `override` is skipped, every other `override` value replaces `base`. Neither input is mutated.

```ts
import { deepMerge } from "@theholocron/object-utils";

deepMerge({ a: 1, nested: { x: 1 } }, { nested: { y: 2 } });
// { a: 1, nested: { x: 1, y: 2 } }

deepMerge({ tasks: ["a"] }, { tasks: ["b"] });
// { tasks: ["a", "b"] }
```
