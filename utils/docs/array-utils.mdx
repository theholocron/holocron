## API

### `isValid(item)`

Returns `true` if `item` is a non-null, non-undefined, non-empty array.

```ts
import { isValid } from "@theholocron/array-utils";

isValid([1, 2, 3]); // true
isValid([]); // false
isValid(null); // false
isValid(undefined); // false
```
