Enforces Conventional Commits format and DCO signing across all `@theholocron` repositories.

**Invoke as:** `/commit-standards`

**Trigger:** writing a commit message, reviewing a commit, opening a PR.

## Conventional Commits

All commit subjects must follow the format:

```
<type>[optional scope]: <description>
```

### Types

| Type | Use for |
| --- | --- |
| `feat` | New feature (triggers minor version bump) |
| `fix` | Bug fix (triggers patch bump) |
| `chore` | Maintenance with no published artifact change |
| `docs` | Documentation-only changes |
| `ci` | CI/workflow changes (won't appear in changelog) |
| `test` | Test additions or changes |
| `refactor` | Code restructuring with no behavior change |
| `perf` | Performance improvement |

### Breaking changes

Append `!` after the type/scope or add a `BREAKING CHANGE:` footer to trigger a major version bump:

```
feat!: drop Node 18 support
```

## DCO signing

Every commit must be signed off with `-s`:

```bash
git commit -s -m "feat: add new thing"
```

This appends the `Signed-off-by:` trailer required by the Developer Certificate of Origin.
