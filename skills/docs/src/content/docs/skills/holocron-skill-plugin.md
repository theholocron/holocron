Scaffolds a new provider plugin package for the `holocron` CLI.

**Invoke as:** `/holocron-skill-plugin`

**Trigger:** user asks to add a new provider plugin to `theholocron/holocron`.

## Usage

Since `v2.0.0-alpha`, plugin scaffolding is a first-class CLI command:

```bash
pnpm exec holocron scaffold plugin <slug>
```

The skill provides guidance for cases where the CLI is not yet available or the scaffolding needs manual adjustment.
