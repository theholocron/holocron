title: Devmoji Config
description: Shared devmoji emoji mappings for conventional commits across theholocron projects.
---

`@theholocron/devmoji-config` provides shared [devmoji](https://github.com/folke/devmoji) configuration for theholocron repos — custom emoji mappings and accepted commit types with a `defineConfig` factory for repo-level overrides.

## Install

```bash
pnpm add -D @theholocron/devmoji-config
```

## Usage

Create `devmoji.config.cjs` at the repo root (`.cjs` required — devmoji uses `require()` and theholocron repos set `"type": "module"`):

```js
/* eslint-disable */
// devmoji.config.cjs — generated by holocron setup, do not edit
const { defineConfig } = require("@theholocron/devmoji-config");
module.exports = defineConfig();
```

With repo-specific overrides:

```js
/* eslint-disable */
const { defineConfig } = require("@theholocron/devmoji-config");
module.exports = defineConfig({
  types: ["wip"],
  devmoji: [{ code: "feat", emoji: "sparkles" }],
});
```

Overrides are **appended** to the defaults — they do not replace them.

## Default mappings

| Type             | Emoji    | Notes                                     |
| ---------------- | -------- | ----------------------------------------- |
| `feat`           | 💥       | New feature                               |
| `fix`            | 🐛       | Bug fix                                   |
| `fail`           | 💩       | Catastrophic failure or emergency hot fix |
| `docs`           | 📚       | Documentation                             |
| `chore`          | 🔧       | Maintenance                               |
| `chore(release)` | 🚀       | Release                                   |
| `chore(deps)`    | 🔗       | Dependencies                              |
| `ci`             | 👷       | CI changes                                |
| `refactor`       | ♻️       | Refactor                                  |
| `test`           | 🚨       | Tests                                     |
| `perf`           | ⚡       | Performance                               |
| `build`          | 📦       | Build changes                             |
| `config`         | ⚙️       | Config file changes                       |
| `lint`           | _(none)_ | Extra accepted type; no emoji mapped      |

`feat` through `build` use devmoji's built-in defaults except where noted. `fail`, `config`, and `lint` are theholocron additions.

## Husky integration

`holocron setup` writes `.husky/prepare-commit-msg` automatically. Manual setup:

```bash
npx husky add .husky/prepare-commit-msg "npx devmoji -e --lint"
```
