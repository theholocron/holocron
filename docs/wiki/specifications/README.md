# Specifications

Specs whose design work is settled. Two kinds live here:

- **`accepted`** — living reference specs (process, documentation, and
  architecture docs) whose decisions are in force and govern how the org works.
- **`archived`** / **`superseded`** — features that shipped, plus explorations
  that were abandoned or replaced.

Each spec captures what the system had to do, not how it was implemented; the
design narrative that outlived the work is kept here for reference.

> **In-progress and proposed specs** live in `.notes/*.spec.md` until the
> design is settled (or the work is dropped), then move here.
