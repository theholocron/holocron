# Specifications

Completed and retired specs — features that shipped, plus explorations that
were abandoned or superseded. Each spec captures what the system had to do,
not how it was implemented; the design narrative that outlived the work is
kept here for reference.

> **In-progress and proposed specs** live in `.notes/*.spec.md` until the
> work is done (or dropped), then move here with `status: archived` or
> `status: superseded`.
