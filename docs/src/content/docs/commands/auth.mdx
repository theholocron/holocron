---
title: "auth"
description: Manage bootstrap credentials in the OS keyring.
---

The `auth` command stores, verifies, and removes provider tokens in the OS credential store (macOS Keychain, Windows Credential Manager, or libsecret on Linux). Tokens stored here are picked up automatically by all other commands.

| Command                                        | What it does                                |
| ---------------------------------------------- | ------------------------------------------- |
| [`auth set`](/holocron/commands/auth-set/)     | Verify a token and store it in the keyring  |
| [`auth unset`](/holocron/commands/auth-unset/) | Remove a stored token                       |
| [`auth check`](/holocron/commands/auth-check/) | Re-verify a stored token                    |
| [`auth list`](/holocron/commands/auth-list/)   | List the providers that have a stored token |

The provider names and the plugin behind each are on the [`auth set`](/holocron/commands/auth-set/) page. See the [Token Reference](../tokens) for the environment variable names and PAT scopes each token needs.
