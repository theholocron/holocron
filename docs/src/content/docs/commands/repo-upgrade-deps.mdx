---
title: "repo upgrade deps"
description: Bump every @theholocron/* pin to its latest version and migrate holocron.config.ts.
---

```bash
holocron repo upgrade deps [--pins-only] [--dry-run]
```

Bumps every `@theholocron/*` pin in `pnpm-workspace.yaml` (the default `catalog:` and every named `catalogs.*`) to its latest published version. It then migrates `holocron.config.ts` from the 7.x preset shape (`const { repo, workflows } = node()`, `repo.requiredChecks` and `workflows:`) to the current composed-preset API (`const preset = node()`, `...preset`, `tasks:` and `extraRequiredChecks:`).

The migration is mechanical transforms only. Review the result, then run `pnpm install && holocron run ci`.

## Options

| Option        | Default | Description                                                         |
| ------------- | ------- | ------------------------------------------------------------------- |
| `--pins-only` | `false` | Only bump the catalog pins; skip the `holocron.config.ts` migration |
| `--dry-run`   | `false` | Print what would change without writing                             |

## Examples

```bash
# Bump the pins and migrate the config
holocron repo upgrade deps

# Pins only
holocron repo upgrade deps --pins-only

# Preview
holocron repo upgrade deps --dry-run
```
