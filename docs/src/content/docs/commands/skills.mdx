title: "skills"

---

Skills are reusable Claude/Codex/Gemini instructions installed from `@theholocron/skills` into `.agents/skills/` with agent-specific symlinks. They're gitignored — `holocron repo setup` re-installs them on every fresh checkout.

| Command                                                | What it does                                      |
| ------------------------------------------------------ | ------------------------------------------------- |
| [`skills install`](/holocron/commands/skills-install/) | Install the skills listed in `holocron.config.ts` |
| [`skills remove`](/holocron/commands/skills-remove/)   | Remove installed skills                           |
| [`skills update`](/holocron/commands/skills-update/)   | Update installed skills to their latest versions  |

## Skills registry

Skills are installed from [`@theholocron/skills`](/holocron/skills/). Standard skills include:

| Skill                   | Description                                                                 |
| ----------------------- | --------------------------------------------------------------------------- |
| `git-safety`            | Git safety rules — guard against destructive operations                     |
| `pr-workflow`           | PR workflow rules — always open a PR, never push directly to default branch |
| `commit-standards`      | Conventional Commits format + DCO sign-off                                  |
| `security-review`       | Security review checklist (OWASP top 10, Node.js pitfalls)                  |
| `holocron-skill-client` | Scaffold a new HTTP client package in `clients/`                            |
| `holocron-skill-config` | Scaffold a new config package in `configs/`                                 |
| `turborepo`             | Turborepo monorepo build system guidance                                    |

## Config example

```ts
// holocron.config.ts
export default defineConfig({
  agent: "claude",
  skills: ["git-safety", "pr-workflow", "commit-standards", "security-review"],
});
```
