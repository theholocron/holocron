---
title: "repo upgrade"
description: Upgrade toolchain version pins across the repo.
---

The `upgrade` subcommand group contains commands for updating version pins across a repo.

| Command                                                      | What it does                                                                           |
| ------------------------------------------------------------ | -------------------------------------------------------------------------------------- |
| [`repo upgrade node`](/holocron/commands/repo-upgrade-node/) | Update every Node.js version pin to a new major                                        |
| [`repo upgrade deps`](/holocron/commands/repo-upgrade-deps/) | Bump every `@theholocron/*` pin to its latest version and migrate `holocron.config.ts` |
