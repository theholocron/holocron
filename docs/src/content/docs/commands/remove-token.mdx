---
title: "remove token"
description: Remove a stored provider token from the OS keyring.
---

```bash
holocron remove token <provider>
```

Removes the token stored for `<provider>` from the OS credential store. Nothing else is changed: a token in an environment variable is untouched.

## Arguments

| Argument     | Default      | Description                                                                                    |
| ------------ | ------------ | ---------------------------------------------------------------------------------------------- |
| `<provider>` | _(required)_ | Provider name, e.g. `github.read`, `vercel` (see [`new token`](/holocron/commands/new-token/)) |

## Examples

```bash
holocron remove token github.read
holocron remove token vercel
```

Related: [`new token`](/holocron/commands/new-token/), [`list tokens`](/holocron/commands/list-tokens/).
