---
title: "resolve checks"
description: Write the configured monitoring checks to a JSON file, the untrusted half of the preview check.
---

```bash
holocron resolve checks --out <file>
```

Loads `holocron.config` and the plugins, and writes the configured `monitoring` checks to `<file>` as JSON. It prints `Resolved N monitoring check(s) → <file>`.

This is the untrusted half of the `check-preview` split. It executes a pull request's own `holocron.config.ts`, so it must never run with a credential worth protecting (such as the Deployment Protection bypass secret) in its environment. [`check resolved`](/holocron/commands/check-resolved/) is the trusted half: it reads this file and makes the authenticated request without loading any config.

## Options

| Option  | Default      | Description                                   |
| ------- | ------------ | --------------------------------------------- |
| `--out` | _(required)_ | The file path to write the resolved checks to |

## Example

```bash
holocron resolve checks --out checks.json
holocron check resolved https://my-preview.vercel.app --checks-file checks.json
```

For a single process with no such split, use [`check monitor`](/holocron/commands/check-monitor/).
