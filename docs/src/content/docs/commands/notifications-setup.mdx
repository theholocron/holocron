---
title: "notifications setup"
description: Apply the server layout a notifications provider declares in holocron.config.ts.
---

```bash
holocron notifications setup [--scope <scope>] [--provider <name>] [--dry-run]
```

Reads the `layout` a `notifications` provider declares in `holocron.config.ts` and creates whatever is missing: categories, channels (with their topics), a webhook per channel that asks for one, and roles. Every step looks things up by name first, so re-running it changes nothing that already exists, and `--dry-run` previews it. A step that fails is reported and the rest still run; the command exits non-zero if any did.

## Declaring a layout

```ts
providers: {
  notifications: [
    "discord",
    {
      guildId: "1303969001822486568", // the server id; not a secret
      layout: {
        categories: [
          {
            name: "ALERTS",
            channels: [
              { name: "alerts", topic: "Needs a human", webhook: true },
              { name: "errors" },
            ],
          },
        ],
        roles: [{ name: "gatekeepers", mentionable: true }],
      },
    },
  ],
}
```

`webhook: true` stores the URL in `HOLOCRON_NOTIFY_WEBHOOK_<CHANNEL>`; `webhook: { name, secret }` overrides the webhook name and the secret name. The command prints each role's id, which is what a workflow needs to ping it.

:::caution
A layout belongs to the server, not to a repo. Put it in **one** repo's config (the one that owns the server), never in a shared preset, or every repo would apply it.
:::

## Options

| Option              | Default | Description                                                      |
| ------------------- | ------- | ---------------------------------------------------------------- |
| `--scope <scope>`   | the org | Webhook secret scope: `repo`, `env=<name>`, or `org=<name>`      |
| `--provider <name>` | —       | Which `notifications` provider, when more than one can provision |
| `--dry-run`         | `false` | Print what would happen without calling the provider             |
