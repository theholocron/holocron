## Install

```bash
npm i -g @theholocron/cli
# or per-project:
pnpm add -D @theholocron/cli
```

## Quick example

```bash
# Authenticate once
holocron new token github.admin  ghp_xxx
holocron new token github.read   ghp_yyy

# Apply full setup
holocron setup

# Sync repo metadata to GitHub
holocron sync

# Check all providers are reachable
holocron doctor
```

See [Getting Started](./getting-started) for the full walkthrough.
