Small helpers for checking and handling arrays.

## Installation

```bash
pnpm add @theholocron/array-utils
```

## Usage

```ts
import { isValid } from "@theholocron/array-utils";

isValid([1, 2, 3]); // true
isValid([]); // false
```

The full [API reference](/holocron/utils/array-utils/api/readme/) is generated from the package's TSDoc comments.
