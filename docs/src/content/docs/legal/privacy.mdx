_Effective 25 October 2026._

This policy covers **Holonet**, the Discord bot operated by The Holocron
maintainers. It is written to say what actually happens, which is very little.

## What Holonet does not do

- It does not read, log or store the content of messages in your server.
- It does not read direct messages.
- It does not sell, share for advertising, or profile anyone.

Holonet calls Discord's HTTP API to create and manage channels, webhooks and
roles, and receives nothing from a server it has not been added to. For role
sync it also reads a member's Discord user and connections at sign-in, the
current holders of a role, and the members of a GitHub team (see Role sync).

## What passes through it

- **Notifications.** GitHub Actions workflows post messages through Discord
  webhooks. These contain repository names, pull request and workflow-run
  links, and short status text. They are sent to Discord and are not copied
  anywhere else by Holonet. Discord stores them under its own policies.
- **Server setup.** When a maintainer runs the setup command, Holonet reads and
  changes the server's channels, webhooks and roles using a bot token. The token
  is kept as a secret by the maintainers and is never published.

## Role sync

Members can choose to connect their Discord and GitHub accounts, so that a
server role can follow membership of a GitHub team. Connecting is optional and
starts when the member signs in with Discord (`holocron notifications link`),
which a maintainer runs on their own machine. For a member who does connect,
Holonet processes:

- the member's **Discord user id** and the **verified GitHub account** linked to
  it (obtained through Discord's OAuth `identify` and `connections` scopes),
- the member's **GitHub login** (their public username), and
- a stored pairing of those, so a role can be added or removed when GitHub team
  membership changes. The pairing is kept in a file in a private repository of
  The Holocron's GitHub organization, readable by its maintainers. Earlier
  versions of the file stay in that repository's history.

Roles are changed only when a maintainer runs `holocron notifications
sync-roles`, not automatically: between runs a role can lag behind the team. To
do that, the command reads the team's members from GitHub and the current
holders of the role from Discord, and adds or removes the role for linked
members.

The sign-in's OAuth access token is used once to read the two ids and Holonet
then asks Discord to revoke it. That request is best effort: if it fails, the
token stays valid until it expires on its own. The token is never stored.
Nothing else about a member is kept.

Revoking Holonet in Discord's **Authorized Apps** settings withdraws Discord's
permission but does not remove the stored pairing, and `sync-roles` keeps using
the pairing until it is deleted. To unlink, ask for the pairing to be deleted
(see Contact).

## Retention

Holonet keeps no message content. GitHub Actions logs are retained under
GitHub's policies and Discord messages under Discord's. Any role-sync pairing is
kept only while it is needed and deleted on request.

## Third parties

Holonet runs on infrastructure from Discord, GitHub and Vercel, each with its own
privacy policy. We don't share data with anyone else.

## Children

Holonet is not directed at children. Discord requires users to be at least 13
(or older, depending on where they live).

## Changes

If this policy changes, the effective date above changes with it.

## Contact

For privacy requests, including deletion of a stored pairing, email
[privacy@theholocron.dev](mailto:privacy@theholocron.dev). Say which Discord
account and GitHub account the pairing is for. We delete a pairing only after
you show you control at least one of those two accounts, and we confirm the
deletion by reply. Deleting removes it from the file; earlier versions
of the file remain in the repository's history.
Revoking Holonet in Discord's **Authorized Apps** settings is immediate but does
not delete the pairing.

For general questions, open an issue at
[github.com/theholocron/holocron](https://github.com/theholocron/holocron/issues).
Don't include personal details in a public issue.
