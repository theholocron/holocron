`@theholocron/skills` is the registry of agent skills that `holocron repo setup` and `holocron skills` install into a repo's `.agents/skills/` directory.

## Installation

```bash
pnpm add -D @theholocron/skills
```

Most repos never install it by hand: list the skill names under `skills` in `holocron.config.ts` and `holocron repo setup` installs them. See [holocron skills](/holocron/commands/skills/).

## Using skills in Claude Code

Skills registered in Claude Code appear as slash commands. Install them with:

```bash
npx skills add @theholocron/skills
```

Then invoke any skill by name, e.g. `/commit-standards` or `/holocron-skill-client`.

## Releases

The package releases on its own version line from the `skills/` folder, with tags `skills-v<version>`. See the [CHANGELOG](https://github.com/theholocron/holocron/blob/alpha/skills/CHANGELOG.md).
