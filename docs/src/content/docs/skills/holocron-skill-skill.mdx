Adds a new skill to the `@theholocron/skills` registry, which lives in `skills/` of `theholocron/holocron`. The standalone `theholocron/skills` repo is archived.

**Invoke as:** `/holocron-skill-skill`

**Trigger:** user asks to create or add a new skill to the skills registry.

## What it produces

A new `skills/src/<name>/` directory with a `SKILL.md` file in the standard frontmatter format:

```markdown
---
name: <name>
description: <one-line description>. INVOKE WHEN: <trigger condition>.
---

# <name>

...skill content...
```

## Categories

**Workflow & safety** — generic skills applicable to any repo (e.g. `git-safety`, `commit-standards`).

**Project-specific** — skills scoped to a particular theholocron repo or task (e.g. `holocron-skill-config`).

The category determines which section of `README.md` the skill is listed under.

## After creating

- Run `pnpm --filter @theholocron/skills verification.unitTests` — the smoke test checks every directory under `skills/src/` has a `SKILL.md`; there is no other registry to edit
- Add the skill to `skills/README.md` in the appropriate section
- Add a corresponding doc page to `docs/src/content/docs/skills/`, a row in its `index.mdx`, and a sidebar entry in the root `astro.config.ts`
- Consuming repos install it by listing the name under `skills` in `holocron.config.ts` (`holocron repo setup`) or with `holocron skills`
